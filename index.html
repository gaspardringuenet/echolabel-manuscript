1 Motivation and Significance

Active acoustics is an indispensable tool for observing pelagic ecosystems. It is the only technology capable of providing continuous observations of organism distribution and behavior at the spatial and temporal scales at which these processes occur (ref). However, extracting ecological information from acoustic data remains a major challenge. Manual delineation of echogram features has long been a common practice in marine acoustics. Targeted biological features are most often fish aggregations such as schools or shoals, but broad-ecosystem surveys provide a motivation for extracting a wider range of objects including scattering layers, or regions with homogeneous frequency-response (ref). Expert annotations may be used for direct scientific analysis (ref), modelling (ref), and increasingly to train deep learning models (ref).

Echogram scrutinizing and annotation has historically been performed using graphical user interface (GUI) based softwares (ref). Most of them are either proprietary (e.g. Echoview, ref) or require a Matlab license (e.g. ESP3, MOVIES3D, MATECHO). Recent years have seen a push towards open-source softwares, well illustrated by the switch of LSSS - one the main GUI-based acoustics software - from proprietary to open-source (ref).

As part of this effort, the Echostack suite has been developped, aiming at providing open-source modular Python tools for interoperable sonar data processing (Lee, Staneva, et al. 2024). The suite is built around its main package Echopype, which focuses on processing and converting raw data into science-ready gridded datasets (Lee, Setiawan, et al. 2024), and is positioned as a future community standard. Echoregions (https://github.com/OSOceanAcoustics/echoregions) is one of the companion packages, and is designed to represent and parse echogram shapes and lines annotations. The combination of Echopype products (standardized \(\text{MVBS}\) datasets saved as netCDF files or Zarr stores) and corresponding Echoregions annotations provides an interface between acoustic data and data analysis or machine learning pipelines within the scientific Python software ecosystem. The Echostack does not currently offer echogram annotation features. Instead, the Echoregions package can read the Echoview annotations files (.EVL and .EVR), and might extend its coverage to other formats in the future.

We identify a current integration gap for users wanting to leverage the power of Echoregions without relying on complex and often expensive GUI softwares. To bridge this gap, we propose Echolabel, a minimalist Python app enabling echogram annotation in Echoregions-readable format. The use case is narrower than current GUIs, focusing purely on displaying echograms and drawing shapes on them. Echolabel is simple, lightweight, and cross-platform. It requires little computing resources, and presents a smooth GUI for annotation. This is achieved by interfacing acoustic data with a widely-used image annotation software (LabelMe, https://labelme.io). Although poorly suited for high-precision annotation requiring additional information (e.g. numerical values, metadata), Echolabel is relevant to annotate large number of easily recognizable acoustic structures.
